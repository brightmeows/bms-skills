# 术语

> 来源：[bmson format specification — bmson-spec 1.0.0-beta documentation](https://bmson-spec.readthedocs.io/en/master/doc/#terminologies)

## 时间单位

共有三种时间单位：

公制时间（SI 时间）：t

: 以*秒*为单位测量。

音乐时间：b

: 以*拍（beats）*为单位测量。一拍的持续时间取决于 BPM 和停止音符。在 4/4 拍号下 1 拍 = 1 个四分音符。

时钟时间（MIDI 时钟）：y

: 以*脉冲（pulses）*为单位测量。一拍被分割为离散的、等距的脉冲。一拍中的脉冲数取决于节拍分辨率。也称为 *ticks*（程序员术语）或 *rows*（[StepMania](http://www.stepmania.com/) 术语）。

## 节拍分辨率

这是 4/4 拍号下每个四分音符的脉冲数。默认值为 `240`，即 1 个四分音符被分为 240 个脉冲 [^1]。

![节拍、脉冲与公制时间之间的关系](https://bmson-spec.readthedocs.io/en/latest/_images/time_units.png)

> [!NOTE]
> 本文档中，我们假定分辨率始终为 `240`。

[^1]: 许多音乐游戏通常使用每四分音符 48 个脉冲（即 4/4 小节 192 个脉冲）。这可以处理 64 分、96 分和 192 分音符，但无法表示五连音（即将一拍等分为 5 个间隔）。240 是 48 和 5 的最小公倍数，可以表示到 80 分、120 分和 240 分音符。

## 维度（什么是 *x* 和 *y*）

bmson 设计为可适配多种类型的音乐游戏。对于大多数音乐游戏，通常有两个常见维度：

- **时间**：何时激活？
- **玩家通道**：如何激活？（例如在 IIDX 风格游戏中，有 8 个可玩通道：1 个转盘和 7 个按键）。

给定这两个常见维度，我们可以像钢琴卷帘一样使用 (x, y) 坐标来表示一个音符，其中 x 坐标代表玩家通道，y 坐标代表音乐时间。

y：脉冲编号

: 我们使用 *y* 而非 *t*，因为音符以*脉冲编号*指定，而非*公制时间*。

x：列/轨道/按键

: 代表音符被激活的玩家通道。

在 `beat-7k` 模式提示下，x = 1 到 7 为按键，8 为转盘。

有关传统模式提示中 x 值的列表，参见 [附录/模式提示规范列表](08-appendices.md)。
