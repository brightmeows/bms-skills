# 拍号与时间

> 来源：[bmson format specification — bmson-spec 1.0.0-beta documentation](https://bmson-spec.readthedocs.io/en/master/doc/#time-signatures)

## 拍号

- **bmson 没有原生的“小节”或“拍号”概念**，而是使用*小节线*的概念。
- 在 BMS 中，音符基于“小节编号”和“小节内分数”。事件的实际时间还取决于拍号。
- 在 bmson 中，一切基于“脉冲编号”，与任何拍号或小节无关。一个脉冲始终是 4/4 拍号下一个四分音符的分数。

### lines :: BarLine[]

- 每个 BarLine 对象包含要在屏幕上显示的小节线的 y 位置。
  - 这可用于模拟拍号的概念。
- `y: 0` 处的第一条小节线可以省略。
  - 无论它存在还是被省略，是否显示该小节线由播放器决定。
- 如果是空数组，则谱面不会有任何小节线，产生类似于 [100% minimoo-G](https://www.youtube.com/watch?v=f1VBBNrSdgk) 的效果。
- 如果未指定（`null` 或 `undefined`），则假设为 4/4 拍号，每 4 个四分音符生成一条小节线。
- 使用默认分辨率时，每 960 个脉冲生成一条小节线。

| 场景 | 示例 |
| --- | --- |
| 4/4 拍号（common time） | <code>lines:<br>  - y: 960<br>  - y: 1920<br>  - y: 2880<br>  - y: 3840<br>  # ...</code> |
| 3/4 拍号（tempus perfectum） | <code>lines:<br>  - y: 720<br>  - y: 1440<br>  - y: 2160<br>  - y: 2880<br>  # ...</code> |
| 从 BMS 映射<br>`#00102:0.75`<br>`#00302:1.25` | <code>lines:<br>  - y: 960    # 000~001: 960<br>  - y: 1680   # 001~002: 720<br>  - y: 2640   # 002~003: 960<br>  - y: 3840   # 003~004: 1200<br>  # ...</code> |

## 计时

### bpm_events :: BpmEvent[] —— 速度变化

在歌曲开始时，音乐将以 `info.init_bpm` 中指定的速度进行。

- 如果 `info.init_bpm` 未指定，则为致命错误。
- 当遇到 `BpmEvent` 时，速度将更改为 `bpm` 字段中指定的值。
- 如果同一时间有多个 `BpmEvent`，BPM 将更改为最后一个。
- 示例：`[{ y: 240, bpm: 100 }, { y: 240, bpm: 120 }]` → 速度更改为 120 BPM。

### stop_events :: StopEvent[] —— 停止

当遇到 `StopEvent` 时，音乐将暂停一段等同于 `duration` 字段中指定的脉冲数的时间。

- 如果同一时间有多个 `StopEvent`，这些停止事件会累加。
- 示例：`[{ y: 240, duration: 240 }, { y: 240, duration: 960 }]` → 滚动停止 1200 个脉冲。

## 事件处理顺序

- 当多个事件发生在同一脉冲时，事件按以下顺序处理：
  - `Note`、`BGAEvent`
  - `BpmEvent`
  - `StopEvent`
- 这与 BMS 播放器解释这些事件的方式一致。
- 如果 `StopEvent` 和 `BpmEvent` 出现在同一脉冲上，速度将先变化，然后音乐暂停。换言之，使用 `BpmEvent` 脉冲处的速度来计算停止的持续秒数，以及类似于 `StopEvent` 的任何计时类。
- 如果 `StopEvent` 和音符出现在同一脉冲上：
  - 如果是 BGM 音符，先播放音频切片，然后音乐暂停。
  - 如果是可玩音符，玩家必须在音乐暂停时（而非音乐恢复时）击打音符。
  - 例如，考虑以下音符和停止：

    ```yaml
    stop: { y: 240, duration: 240 }
    note: { y: 240 }
    ```

  - 这意味着位置 `y: 240` 覆盖了一段时间范围，而非一个精确的时间点（因为暂停期间速度为零）。
  - 当当前 BPM 值为 60 时，*y（脉冲编号）*与 *t（公制时间）*的对应关系如下：

    | y（脉冲） | t（秒） |
    | --- | --- |
    | 0 | 0.0 |
    | 120 | 0.5 |
    | 239 | 239 / 240 |
    | 240 | 1.0 ≤ t ≤ 2.0 |
    | 241 | 481 / 240 |

    在 `y: 240` 处时间是模糊的。

    因此，本规范定义 `y: 240` 处的音符必须在 `t = 1.0`（暂停开始时）被激活。

> **扩展提示：添加计时类时**
>
> 如上所述，任何累积性计时类应遵循 `StopEvent` 的格式，并使用以脉冲为单位的持续时间。固定量计时类应使用与其类对应的单位，就像 `BpmEvent` 那样。
